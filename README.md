# Kimi K2 Chat — kimi-k2.net

Chat with Kimi K2 online in your browser — 2 free conversations, then one-time credit packs.

**Homepage:** [https://kimi-k2.net/](https://kimi-k2.net/)

## What it is

[kimi-k2.net](https://kimi-k2.net/) is an independent, browser-based chat service for Kimi models. Some AI processing is provided through the Moonshot AI API. You sign in with Google, and new accounts get **2 free conversations** — no API key, no local GPU, no setup.

> Independence note: kimi-k2.net is a third-party service. It is **not affiliated with, endorsed by, sponsored by, or operated by Moonshot AI**. "Kimi" and "Moonshot AI" are trademarks of their respective owners. For official model specs, licensing, and API docs, see Moonshot AI's official documentation.

## What you can do with it

- **Chat in the browser** with conversation history — [Kimi Chat workspace](https://kimi-k2.net/kimi-chat)
- **Work through code**: debugging, shell commands, structured problem-solving
- **Summarize and organize** writing, research notes, and complex questions
- **Use supported documents as context** (e.g. reports or CSV files) when file access is available for your account
- **Learn to prompt Kimi** with the [Kimi K3 guide and prompt templates](https://kimi-k2.net/models/kimi-k3) and the [guides & analysis section](https://kimi-k2.net/posts) (developer guide, API platform comparison, use cases)

Example prompts shown on the site:

- "Generate a shell command to find all '.log' files larger than 10MB in my home directory and compress them."
- "Analyze the attached CSV file of housing prices, then create a web page to visualize the price distribution and trends."
- "Compare the Q3 financial reports of Apple and Microsoft (attached), and summarize the key performance indicators in a markdown table."
